## About the Project
This project contains 10 Python case studies completed as part of the Activity-Based Learning assignment. Each program demonstrates Python programming concepts through practical problems.

## Case Studies

1. **Attendance Recovery Computation** – Calculates the additional classes required to reach the target attendance percentage.
2. **Advanced Numeric Pattern Generator** – Generates a diamond pattern using stars.
3. **Password Policy Validation Engine** – Checks whether a password satisfies security requirements.
4. **String-Based Examination Answer Evaluation** – Evaluates answers and calculates the score.
5. **Text Compression Using Character Runs** – Compresses consecutive repeated characters.
6. **Repeated Word and Phrase Detection** – Identifies repeated words in a text.
7. **Student Marks Matrix Analysis** – Calculates student totals, averages, and the top performer.
8. **Weekly Electricity Consumption Matrix** – Analyzes daily and weekly electricity consumption.
9. **Tuple-Based Product Catalogue Audit** – Calculates inventory value and identifies low-stock products.
10. **Food Waste Monitoring System** – Calculates food leftovers and waste percentages.

## Requirements
- Python 3.x

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Navigate to the `programs` folder.
4. Run any program using:

```bash
python case1_attendance.py
```

Replace the filename with the program you want to execute.
